# 使用示例

[English](usage.md) · [安装说明](../README.zh-CN.md#安装)

在 Codex 或 Claude Code 中打开目标 GPUI 项目后使用以下提示，按项目实际情况替换路径和组件名称。

下面五个示例使用 Codex 的 `$gpui-liquid-glass` 前缀。在 Claude Code 中，将前缀替换为 `/gpui-liquid-glass`，其余提示内容保持一致。例如：

```text
/gpui-liquid-glass 为导航侧栏实现 Apple 原生 Liquid Glass。
背景取样桌面，让面板几何跟随尺寸变化，并验证旧版 macOS 降级。
```

## 添加取样桌面的玻璃侧栏

```text
$gpui-liquid-glass 为导航侧栏实现 Apple 原生 Liquid Glass。
背景取样窗口后面的桌面，保持正文可读，遵循现有主题和缩放规则。
让原生面板跟随侧栏尺寸变化和显示/隐藏动画。
提供旧版 macOS 材质降级，并保留其他平台现有的呈现方式。
核对实际调用位置，说明完成了哪些真实窗口验证。
```

预期结果包括真实材质视图、上方的透明合成、同步的几何，以及明确的背景来源。

## 将工具栏控件组成玻璃胶囊

```text
$gpui-liquid-glass 把现有工具栏控件组成原生玻璃胶囊。
使用窗口底色作为背景，沿用已有动作和快捷键。
保留悬停、按下、选中、禁用及键盘焦点状态。
如果相邻胶囊需要融合，选择并验证容器的 spacing。
```

预期结果应将胶囊接入原生面板注册，并验证交互状态。位于窗口纯色背景上的胶囊不能直接证明它取样了编辑正文。

## 修复旧版 macOS 崩溃

```text
$gpui-liquid-glass 排查并修复在旧版 macOS 启用玻璃时的崩溃。
追踪能力选择、原生构造、圆角更新和清理流程。
检查所有新 AppKit 类的使用是否受运行时保护。
在能证明行为变化的最低层增加回归验证，并说明是否在旧系统真实窗口中测试。
```

预期结果应保护完整的降级生命周期，包括创建后的属性更新。

## 只读分析已有 worktree

```text
$gpui-liquid-glass 只读分析 /path/to/worktree 中的 Liquid Glass 实现。
说明合成层次、实际面板调用位置、背景来源、系统支持、布局同步和窗口清理。
区分源码结论与尚未观察到的原生窗口表现，给出相关代码位置。
```

预期结果应指出真正使用玻璃的区域，并以源码支撑结论。

## 评估滚动正文折射

```text
$gpui-liquid-glass 评估当前 GPUI 后端能否让玻璃工具栏折射后方滚动的正文。
检查渲染表面和已有背景取样 API。
说明可行实现与限制，再提出渲染器或原生视图结构的调整方案。
```

预期结果应明确正文位于合成层次的哪一层，以及材质能否实际取样。
